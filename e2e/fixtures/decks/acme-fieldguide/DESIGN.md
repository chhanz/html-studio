# Acme Field

## Overview

Acme Field is a paper field notebook: a warm canvas `{colors.canvas}` (#fffdf8), ink `{colors.ink}` (#1f2937), and one rust accent `{colors.primary}` (#7c2d12) for headings and pills. Type is set in `Georgia`.

## Colors

### Brand
- **Rust** (`{colors.primary}` — #7c2d12): headings, pills, the logo mark.
- **Canvas** (`{colors.canvas}` — #fffdf8): slide background.
- **Ink** (`{colors.ink}` — #1f2937): body text.
